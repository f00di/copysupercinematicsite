# Atelier North (cinematic construction site)

Next.js + TypeScript demo/template site for a fictional Austin design-build firm, "Atelier North". Phone, email and address in `content/site.ts` are placeholders.

- Content lives in `content/` (`site.ts`, `services.ts`, `residence-panels.ts`); components in `components/`, routes in `app/`.
- Commands: `npm run dev`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run test:e2e`, `npm run build`, `npm run media:optimize`.
- Edit copy in `content/`, not inside components.
- Ignore `playwright-report/`, `test-results/`, `node_modules/`.
